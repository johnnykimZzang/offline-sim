## 2026-04-16 — 고객 수 지표 추가 + 운영 현황 스트립 + 툴팁 수정

### 새 지표 3종 (슬라이더 추가)
- **일 영업시간** (`operations.operatingHours`, 기본 8시간) — 시간당 체류 고객·피팅룸 회전율 계산 기준. 기존 하드코딩(480분)을 슬라이더로 노출.
- **피크 유입 집중도** (`fitting.peakTimeShare`, 기본 30%) — 일 유입 중 피크 2시간에 집중되는 비율. OpsStrip의 피크 시간당 체류 고객 계산에 사용.
- **오프라인 재방문율** (`crm.returnVisitRate`, 기본 10%) — 방문 고객 중 구매 이력 있는 재방문 비율.

### 운영 현황 스트립 (OpsStrip)
KpiGrid와 DiffSummary 사이에 신규 삽입. 표시 지표:
- **일 평균 유입** — `totalVisitors / openDays`
- **시간당 체류 (평균)** — 리틀의 법칙: `avgVisitors × avgStayMin / 60 / operatingHours`
- **시간당 체류 (피크 2시간)** — `(avgVisitors × peakShare% / 2) × avgStayMin / 60`
- **일 재방문 고객** — `avgVisitors × returnVisitRate%`
- **영업 가동일** — 실제 영업 일수

### 툴팁 수정
- `createPortal(…, document.body)` 적용 → 사이드바 `overflow: auto` 부모에 잘리지 않음.
- `opacity: 1` 명시, `boxShadow` 강화 → 불투명하게 표시.
- 좌·우 경계 모두 클램프 → 화면 끝에서 잘리지 않음.

## 2026-04-09 — SaaS Full-Width 레이아웃 전환 + 반응형

### 레이아웃
- **양옆 여백 제거** — `#root`의 `width: 1126px; margin: 0 auto` 제거. 뷰포트 100% 풀 와이드 사용.
- **사이드바 축소** — 310px → CSS 변수(`--sim-sidebar-width: 260px`). 태블릿에서는 240px 자동 적용.
- **우측 패널 여백 축소** — 좌우 `16px` → `8px`. 콘텐츠 사용 면적 확대.

### 반응형 (모바일 ≤ 767px)
- **Off-canvas 사이드바** — 모바일에서 사이드바가 화면 밖으로 숨겨지고 햄버거 버튼으로 열림.
- **Backdrop + ESC 닫기** — 사이드바 열린 상태에서 배경 클릭 또는 ESC로 닫기.
- **Body scroll lock** — 사이드바 열릴 때 뒷 화면 스크롤 방지.
- **Viewport resize 자동 닫기** — 768px 이상으로 넓어지면 사이드바 자동 닫힘.

### 내부 구조
- 레이아웃 치수를 CSS 변수(`--sim-sidebar-width`, `--sim-page-gutter`)로 토큰화.
- breakpoint: mobile ≤767 / compact 768~1199 / wide ≥1200.

## 2026-04-09 — Phase 6: 권고형 UX 전환

### 화면 구조
- **KPI 1+3+4 위계** — 월매출 hero(대형) + 목표달성률/회원/재구매(중형) + 구매건수/객단가/유입/피팅(소형). 시선이 자연스럽게 흐른다.
- **탭 2단 재배열** — 주 탭(민감도·목표 역산·일별 캘린더)과 보조 탭(주간·퍼널·비교)이 분리됨. 기본 탭이 민감도로 변경.

### 좌측 슬라이더 패널
- **"지금 손댈 레버 Top 3" 카드** — 패널 상단 sticky. 현재 시나리오 기준 상위 3개 변수와 예상 영향도(+X%) 표시. 클릭 시 해당 슬라이더로 스크롤.
- **민감도 배지** — Top 5 슬라이더에 `#순위` 배지. 나머지는 dim 처리. "어디부터 만질지"가 바로 보인다.
- **섹션 영향도 micro bar** — 각 섹션 헤더에 그룹 최대 영향도 비례 bar.

### 비교/요약
- **DiffSummary 한 줄 요약** — KPI 위에 "유동인구 +15%, 구매전환율 -2% · 매출 +8.4% 예상" 형식. 기준 프리셋 라벨 상시 표시. 프리셋 변경 시 "현재 기준 업데이트됨" 토스트.

### 인사이트 패널
- **reason + action 구조** — 단순 메시지 → 원인 설명 + "→ 유동인구 +10% 검토" 버튼. 클릭 시 해당 슬라이더로 이동.

### 첫 진입
- **Empty hero 배너** — 슬라이더 변경 전 최초 진입 시 "현실 시나리오부터 불러오기" 안내. 건너뛰기 가능, 1회성.

## 2026-04-09 — Phase 5: 민감도 분석

### 추가
- **민감도 탭** — 각 변수를 ±5/10/20% 바꿨을 때 월 매출이 얼마나 달라지는지 tornado chart로 표시.
- **반응 배율** — 입력을 1% 바꿀 때 매출이 몇 % 움직이는지. 1.0이면 비례, 2.0이면 2배 증폭.
- **Top 5 하이라이트** — 상위 5개 변수를 그린 틴트로 강조. 의사결정 우선순위 바로 판단.
- **도메인 색상 범례** — 수요/제품/전환/피팅/CRM/운영별 색상으로 bar 틴트.

### 가치
- "슬라이더를 어디부터 만져야 하나"에 대한 객관적 답. 추측 대신 수치.
- 매출에 영향 없는 변수(예: QR 스캔률)는 자연스럽게 하위권 → 불필요한 논의 제거.

## 2026-04-08 — Phase 2: 영속화 + 프리셋

### 추가
- **자동 저장** — 슬라이더 변경 시 자동으로 localStorage에 저장. 새로고침해도 유지.
- **시나리오 프리셋 4종** — 보수 / 현실 / 낙관 / 목표(1억). 상단 칩 클릭으로 즉시 적용.
- **변경 표시** — 기본값과 다른 슬라이더 옆에 작은 그린 점 표시.
- **섹션 초기화** — 각 섹션 헤더 우측 `↺ 초기화` 버튼으로 해당 도메인만 복원.
- **전체 초기화** — 프리셋 바 우측 `↺ 전체 초기화` 버튼으로 모든 값 기본값 복원.

### 개선
- 섹션에 변경 항목 있을 때만 초기화 버튼 노출 (불필요한 클릭 유도 X).
- 도메인 백필 로직: schema에 새 필드 추가 시 기존 저장값과 자동 병합.

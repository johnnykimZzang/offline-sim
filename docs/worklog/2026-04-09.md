## 작업 1 — Phase 5: 민감도 분석

### 변경 목적
"어떤 변수가 매출을 가장 크게 움직이나" 객관적 답 제공. 의사결정 우선순위 도출.

### 수정 파일
- `src/lib/sensitivity.js` — 신규. `runSensitivity(state, deltaPct)` export. 25개 변수 대상.
- `src/components/views/SensitivityView.jsx` — 신규. Tornado chart + ±5/10/20% 토글 + 도메인 범례.
- `src/App.jsx` — `sensitivity` 탭 추가.

### 문서 반영
- `docs/architecture.md` (파일 구조)
- `docs/decisions.md` (Phase 5 판단 기록)
- `docs/changelog.md` (사용자 관점)

### 검증
- `npm run build` 통과 (122ms, 44 모듈)

### 남은 이슈
- 탭 개수가 7개로 늘어남 → 모바일에서 줄바꿈 확인 필요 (flexWrap 되어 있음).
- 민감도 계산은 매 렌더 시 25회 × 2(up/down) = 50회 `simulateMonth` 호출. state 변경 시만 재계산 (useMemo) → 체감 문제 없을 것으로 예상. 느려지면 debounce 추가.
- 변수 간 상호작용(예: 전환율 × 유입) 미측정. 필요해지면 2차 분석 탭 별도.
- 정수형 필드(roomCount, staffCount)는 ±1 단위로 보정했지만, %로 환산하면 deltaPct와 달라짐 → 탄력성 비교 시 주의.
